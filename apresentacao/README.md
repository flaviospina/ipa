# Abordagem ACP · Indicador IPA — apresentação executiva

Deck de 21 slides para reunião de diretoria. Gerado por código (`build.js` + pptxgenjs),
o que permite reeditar textos e regerar o arquivo sem retrabalho manual.

## Arquivos

| Arquivo | O que é |
|---|---|
| `abordagem-acp-ipa.pptx` | O deck (16:9, 13,333" × 7,5"). Abre no PowerPoint, Keynote ou Google Slides |
| `abordagem-acp-ipa.pdf` | Versão para envio prévio / impressão |
| `build.js` | Gerador. `node build.js` reconstrói o `.pptx` |

## Como levar para o Google Slides

Para atualizar a apresentação existente **mantendo o mesmo link**:
`Arquivo › Importar slides › Enviar` → selecionar o `.pptx` → marcar todos os slides →
manter "Manter formatação original" → Importar. Depois apagar os slides antigos.

Para uma apresentação nova: arrastar o `.pptx` para o Drive → abrir com Google Slides.

## Sistema visual

Estrutura "sanduíche": fundos escuros na abertura, nos slides de virada e no fechamento;
fundo claro nos slides de conteúdo.

| Papel | Hex |
|---|---|
| Navy profundo (dominante) | `0E2233` |
| Cartão sobre escuro | `1B3A54` |
| Cartão sobre claro | `F1F5F8` |
| **Atenção** — terracota | `E07A5F` |
| **Comunicação** — âmbar | `E9B44C` |
| **Procedimento** — teal | `2A9D8F` |

As três cores não são decorativas: cada uma pertence a uma variável do modelo ACP e
é usada sempre para a mesma variável, do primeiro ao último slide. O motivo visual
repetido são os medalhões circulares (A / C / P e numeração de etapas).

Tipografia: Cambria (títulos) + Calibri (corpo) — ambas embarcadas no Office, sem
risco de substituição de fonte na máquina do cliente.

## Dados citados (slide 3)

- 52% deixaram de comprar de uma marca após experiência ruim — PwC, *Customer Experience Survey 2025*
- 29% pararam especificamente por atendimento ruim — mesma fonte
- 86% dispostos a pagar mais por experiência superior — PwC, *Experience Is Everything*

O gráfico do slide 8 e o mapa de calor do slide 13 são **ilustrativos** e estão
rotulados como tal no próprio slide — representam o modelo, não medições reais.
Substituir pelos dados da primeira aplicação assim que existirem.
